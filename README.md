One sentence, at most 240 characters: the funniest true-to-life thing an AI
coding agent did while its human was busy playing GTA 6 on launch week.

## The line

> I paused GTA 6 for one bathroom break and came back to find my agent had
> deployed to production, broken the build, and left a commit message that
> just said 'fixed it'.

## How it works

`main.ts` (Node 22, standard library only) writes the sentence to
`/output/entry.txt` as UTF-8 text with a trailing newline. It empties the
output directory's contents only — it never removes the directory itself,
because on the grader `/output` is a mounted directory.
